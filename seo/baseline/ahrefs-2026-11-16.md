## Finding: spam link attack (Master Plan §3.6 NEG, §18.2)
From May 2026 the profile grew from ~39 to ~888 referring domains. The new links are almost all from link-seller / spam sites (e.g. `*.shop` domains such as rankboostly.shop, pbnseolinks.shop, buyseobacklinks.shop, authoritybacklinks.shop, linkrankpro.shop; `buybacklinks.agency`, `rank-top.click`, `fiverr-quality-seo-at-affordable-rates.site`) using anchors that advertise "ecommwizards.com" as an SEO/backlink/PBN service:

| Anchor (shortened) | Ref. domains | Dofollow links |
|---|---|---|
| "Before discovering SEOExpress.org, I struggled with content marketing for ecommwizards.com…" | 300 | 0 |
| "Build Powerful SEO Authority with Premium Backlinks ecommwizards.com" | 250 | **250** |
| "done-for-you SEO for SEO resellers: ecommwizards.com runs … DR boost services…" | 211 | 0 |
| "ecommwizards.com" (bare domain) | 102 | 220 |
| "Scale ecommwizards.com with premium guest posts…" | 43 | 0 |
| "High Quality Dofollow Backlinks DA 50 PA 40 Premium PBN Network Service ecommwizards.com…" | 41 | **43** |
| "Reliable Guest Post Service for ecommwizards.com…" | 14 | 14 |

- Estimated genuine referring domains: **~30–40** (the pre-May level).
- Likely linked to the ~409k `?c=` spam URLs already blocked/410'd (same period, same pattern).
- These were not built by us (owner to confirm no past SEO vendor bought links).

### Recommended response (needs owner decision)
1. **Day 0:** GSC → Manual actions + Security issues. If a manual action exists → full cleanup + disavow + reconsideration request (§18.2).
2. **No manual action:** Google says it ignores most spam links automatically. But this is a large, clear, anchor-spam pattern (incl. ~300 dofollow "PBN / premium backlinks" anchors) on a small site, so a **domain-level disavow file of the obvious spam domains** is a reasonable precaution. Cost to export the full list: ~13k Ahrefs units (888 rows); can wait until the 10 Dec unit reset.
3. Monitor monthly: referring-domain growth, new spam anchors, GSC "Links" report.
4. The real authority work (§12) starts from ~DR 15 with ~30–40 genuine domains.
